# SmartCart Customer Segmentation

## Overview

SmartCart Customer Segmentation is an unsupervised machine learning project that segments customers into meaningful groups based on their characteristics and purchasing behavior.

The project follows an end-to-end machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, dimensionality reduction, clustering, and cluster evaluation.

## Objectives

- Analyze customer data and identify meaningful patterns
- Preprocess and transform raw customer data
- Engineer relevant features for clustering
- Segment customers using unsupervised learning techniques
- Compare different clustering approaches
- Evaluate and interpret the resulting customer segments

## Technologies Used

- Pandas
- NumPy
- Matplotlib

- Jupyter Notebook

## Machine Learning Techniques

- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Feature Scaling
- Principal Component Analysis (PCA)
- K-Means Clustering
- Agglomerative Clustering
- Elbow Method
- Silhouette Analysis
- Cluster Profiling
